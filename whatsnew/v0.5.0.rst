v0.5.0 (April 2026)
-------------------

Breaking Changes
~~~~~~~~~~~~~~~~
* Rename scan-log/check-out CSV field `Operator` to `User` for consistency with
  updated terminology. Existing downstream parsing that expects `Operator` must be
  updated. (:pull:`16`)


Enhancements
~~~~~~~~~~~~
* Add new checkout feature to allow users to checkout substrates to track their usage.
  (:issue:`13`, :pull:`14`)


Maintenance
~~~~~~~~~~~
* Major refactor and clean up (:pull:`19`):
  - Remove unused internal helpers ``get_unsaved_count`` and ``is_data_type``.
  - Simplify ``get_process_color`` and ``get_process_info`` — redundant validity
    checks removed in favour of ``dict.get`` defaults.
  - Trim verbose Args/Returns docstrings on trivial utility functions throughout
    ``tracker_utils.py`` and ``qr_utils.py``.
  - Remove ``# ===`` visual separator blocks from ``generate_custom_qr_codes.py``
    and fix ``# --- Error Messages ---`` section header to ``# --- Display Names ---``.


Documentation
~~~~~~~~~~~~~
* Checkout scan log splits by month (:issue:`17`, :pull:`18`)
