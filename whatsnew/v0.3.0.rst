v0.3.0 (TBD)
------------------------

This release removes the deprecated CLI interface and streamlines the codebase
to focus on the GUI experience. Other documentation improvements and enhancements have
also been pushed.

Breaking Changes
~~~~~~~~~~~~~~~~
- **CLI Removed:** The command-line interface (``process_tracker.py``) has been
  completely removed. All users must use the GUI interface
  (``process_tracker_gui.py``).
- Executable: Only GUI executable is now built (``process_tracker_gui_v<version>.exe``).
  The CLI executable is no longer available.


Maintenance
~~~~~~~~~~~
- Remove ``src/process_tracker.py`` (deprecated CLI interface)
- Remove ``tests/test_process_tracker.py`` (CLI-specific tests)
- Remove ``tests/test_integration.py`` (CLI/GUI consistency tests, no longer needed)
- Update build scripts to only build GUI executable
- Simplify documentation to focus on GUI usage
- All core functionality remains tested in ``tests/test_tracker_utils.py``
- Remove upload step of coverage reports to Codecov from CI workflow
  (:issue:`62`, :pull:`63`)


Documentation
~~~~~~~~~~~~~
- Update README and GUI to specify operator username format to be their NREL username
  (:issue:`60`, :pull:`61`)
