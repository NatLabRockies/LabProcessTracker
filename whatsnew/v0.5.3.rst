v0.5.3 (November 2026)
------------------------


Breaking Changes
~~~~~~~~~~~~~~~~


Enhancements
~~~~~~~~~~~~
* Checkout dialog now requires the pattern (Pixel/Module) and TCO
  (``Vendor-TCO-Resistivity``, e.g. ``Sz-ITO-20``, ``NSG-FTO-7``, or a custom
  value), recorded as ``Pattern`` and ``TCO`` columns in
  ``checkout_log_YYYY-MM.csv``. Missing fields are flagged in red in the dialog,
  and ``UNDO`` messages now show the removed record's pattern and TCO.
  Existing monthly logs with the legacy ``Timestamp,User,SampleID`` header
  (including UTF-8 BOM files saved by Excel) are upgraded on the next save via
  an atomic rewrite; logs with any other header are left untouched and the save
  fails with an error. (:issue:`22`, :pull:`24`)
* The ``S%:`` sample prefix is now optional. Bare sample IDs are accepted in
  both the old hyphenated format (``YYMM-NN`` / ``YYMM-NNN``, e.g.
  ``2511-09``) and the new hyphenless format (``YYMMNN`` / ``YYMMNNN``, e.g.
  ``2601123``). Existing ``S%:`` labels still work; the prefix is stripped, so
  ``S%:2601123`` and ``2601123`` log the same ID. IDs are logged exactly as
  scanned, so ``2601-123`` and ``2601123`` remain distinct. The legacy-format
  warning is no longer shown for unprefixed IDs.
* Checkout bulk ranges support hyphenless IDs: the first 4 digits (``YYMM``)
  are fixed and only the trailing counter increments, with zero-padding
  preserved (``2503015`` → ``2503016`` …). Ranges that would roll into the
  next month (e.g. ``2503999`` + 2) are rejected.


Bug Fixes
~~~~~~~~~
* ``S%: 2601-01`` (whitespace after the sample prefix) was accepted and logged
  with a leading space. It is now rejected as an invalid scan.


Maintenance
~~~~~~~~~~~
* Fixed flake8 violations in ``tracker_utils``: removed the unused ``global``
  statements in ``load_process_data`` and ``load_tray_data`` (``F824``; the
  module-level dicts are mutated in place, so behavior is unchanged) and
  rewrapped the over-length ``parse_input`` docstring (``E501``). (:pull:`24`)
* QR generation scripts now emit unprefixed sample IDs; the test QR set covers
  new hyphenless, old hyphenated and ``S%:``-prefixed samples.


Testing
~~~~~~~
* Added tests for checkout log upgrades from BOM-prefixed legacy files,
  rejection of unexpected headers, atomic-write failure handling, and checkout
  pattern/TCO validation. (:pull:`24`)
* Added tests for optional ``S%:`` prefix, hyphenless sample IDs (valid and
  invalid patterns), whitespace after the prefix, and hyphenless checkout
  ranges.


Documentation
~~~~~~~~~~~~~
* Documented the checkout pattern/TCO selectors and the monthly checkout log
  header upgrade in ``README.md``. (:pull:`24`)
* Updated the QR code format section of ``README.md`` for the optional
  ``S%:`` prefix and hyphenless sample IDs.
